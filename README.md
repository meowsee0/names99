# 99 имён Аллаха

Приложение для изучения имен Аллаха. Бесплатно, с прогрессом и мотивацией.

Как пользоваться приложением

Важно: открывать приложение нужно через браузер (Safari на iPhone, Chrome на Android).

Для iPhone (Safari)

1. Откройте ссылку на приложение в Safari.
2. Внизу экрана нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Прокрутите список вниз и выберите «На экран „Домой“».
4. Нажмите «Добавить» в правом верхнем углу.
5. Теперь иконка приложения появится на экране «Домой». Открывайте приложение только через неё.

Для Android (Chrome)

1. Откройте ссылку в браузере Chrome.
2. Нажмите на значок с тремя точками в правом верхнем углу.
3. Выберите «Установить приложение» или «Добавить на главный экран».
4. Подтвердите действие. Иконка появится на главном экране телефона.
5. Открывайте приложение через эту иконку.

Про прогресс
Ваш прогресс хранится только в вашем телефоне и браузере. Чтобы не потерять его при смене устройства:

1. Зайдите в «Настройки» приложения и нажмите «Показать копию».
2. Скопируйте текст и сохраните его, например, в заметках.
3. На новом телефоне откройте «Настройки», вставьте текст в поле и нажмите «Загрузить из поля».

Не очищайте данные браузера, иначе прогресс пропадёт.
